# FEC-E4 明文与密文双入口一致性

| 项目 | 内容 |
| --- | --- |
| 对应条目 | FEC-06 密态计算正确性 |
| 地点 | 鲲鹏 virtCCA CVM，网关 :8000 |
| 时间 | 首轮 2026-09-16（dual_entry_01），复测 2026-09-18 |
| 结果 | 通过：3 轮输出 SHA-256 逐轮完全相同 |

## 目的

确认密态计算解密后的结果与明文对照完全一致，不只是“在容差内接近”。

## 方法

1. 每轮生成唯一 prompt，避免缓存命中。
2. 同一 prompt 分别走密文入口（客户端加密）和明文对照入口，`max_tokens=24`，温度 0。
3. 两个入口的先后顺序逐轮交替，排除顺序影响。
4. 比较两个入口输出的 SHA-256。

脚本：`security_fec_dual_entry.py`

## 结果

| 轮次 | 顺序 | prompt SHA-256（前 8 位） | 两入口输出一致 |
| --- | --- | --- | --- |
| 1 | 密文 → 明文 | 91843db9 | 是 |
| 2 | 明文 → 密文 | 72f1fcec | 是 |
| 3 | 密文 → 明文 | 7c6bd290 | 是 |

`unique_prompts=true`，`all_entries_match=true`。

## 证据文件

- `../证据/鲲鹏310P_复测/dual_entry/result.json`

## 说明

两个入口共用同一个 OTP 引擎：本实验证明的是“加密封装与解密不改变结果”。与完全不带 OTP 的纯明文引擎的对照需要停服务，本次未做。

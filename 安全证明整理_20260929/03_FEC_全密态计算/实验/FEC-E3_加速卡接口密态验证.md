# FEC-E3 加速卡接口密态验证

| 项目 | 内容 |
| --- | --- |
| 对应条目 | FEC-05 CPU—加速卡接口密态验证 |
| 地点 | 鲲鹏 virtCCA CVM 内引擎容器，独立测试进程（生产引擎不受影响） |
| 时间 | 首轮 2026-09-16（npu_01），复测 2026-09-18 |
| 结果 | 通过：96/96 |

## 目的

在加速卡的输入 / 输出接口处，确认进卡的是 OTP 密态分量，卡返回的也是密态分量，且解密后结果正确。

## 方法

1. 把引擎源码（`q8_ops.c`、`st35.c`、`otp_rng.h` 等，均记录 SHA-256）复制出生产目录，与探针 `security_npu_extended_probe.cpp` 一起编译为独立进程。
2. 构造 96 个独立合成样本：4 种数据模式（全零、稀疏、正极值、负极值）× 2 条路径（`raw`、`raw_split`）× 不同形状和重复次数。
3. 在 H2D / D2H 处直接截取原始整数分量，**关闭 CPU 自动补正**，与 CPU 参考实现逐个比对。
4. 同一输入重复发送，比较 H2D 指纹是否不同（验证一次一密）。

脚本：`security_run_npu_extended.py`、`security_npu_extended_probe.cpp`

## 结果

| 指标 | 结果 |
| --- | --- |
| 用例数 | 96，全部 rc=0 |
| 输出不一致 | 0 |
| D2H 原始整数分量不一致 | 0 |
| 同一输入重复发送 H2D 指纹不同 | 是（`repeat_fingerprint_differs=true`） |
| 测试前后生产后端请求数 | 不变，测试后空闲 |

## 证据文件

- `../证据/鲲鹏310P_复测/npu/result.json`（含每个用例的逐行输出与源码摘要）

## 说明

- 观测点是软件接口（memcpy 前后），不是物理 PCIe 总线抓包。
- H2D 指纹使用 FNV-1a64，只用于证明样本不重复，不作为密码学证明。

# FEC-E7 日志与临时文件残留

| 项目 | 内容 |
| --- | --- |
| 对应条目 | FEC-02 隔离存储（密钥与明文不落在可观测位置） |
| 地点 | 鲲鹏宿主与 CVM 两侧文件系统、容器日志 |
| 时间 | 首轮 2026-09-16（residue_01），复测 2026-09-18 |
| 结果 | 通过：业务标记在文件与容器日志中 0 命中，对照文件可搜出 |

## 方法

1. 生成唯一标记，先在 CVM 和宿主各放一个含该标记的**对照文件**。
2. 发送一次带该标记的加密请求（复测耗时 11,672 ms，成功）。
3. 在 CVM 和宿主两侧全盘搜索标记，并检索容器日志。
4. 判定：对照文件必须被搜到，其他任何文件和日志中都不能出现标记。

脚本：`security_fec_residue.py`

## 结果

| 检查 | CVM | 宿主 |
| --- | --- | --- |
| 含标记的文件（除对照外） | 0 | 0 |
| 对照文件被搜到 | 是 | 是 |
| 容器日志含标记 | 否 | — |

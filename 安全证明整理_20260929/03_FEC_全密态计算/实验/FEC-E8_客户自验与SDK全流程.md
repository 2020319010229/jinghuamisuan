## 2. SDK 全流程事件（21 个）

身份验证开始 → 证书提交 → 收到证书 → 身份验证结束 → **prompt 加密开始 / 结束** → 生成准备 → 流式开始 → 提交生成请求 → 收到响应头 → 4 次（收到加密 delta → 解密 delta）→ 收到 done → 客户端关闭。

每个事件记录单调时钟与 UTC 时间，不保存 DEK 或业务明文。

## 3. 双客户端隔离

同一宿主进程内两个客户端，各自使用不同 DEK 和会话，串行和并发各跑一遍（并发区间重叠 15,072 ms）。

| 检查 | 结果 |
| --- | --- |
| 4 个流都完成并解密 | 通过 |
| 客户端 0 / 1 并发结果与串行结果一致 | 通过 |
| 客户端 0 / 1 的响应用对方密钥解密被拒（串行、并发各一次） | 通过 |
| 两个参考输出可区分 | 通过 |
| 两个请求区间确实重叠 | 通过 |
| 后端恰好收到 4 个请求，结束后空闲 | 通过 |

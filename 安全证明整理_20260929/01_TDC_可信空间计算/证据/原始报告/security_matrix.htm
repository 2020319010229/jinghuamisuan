二、安全证明矩阵

方案一 TDC（CPU-TEE + 通用加速卡原生直通）

核心安全主张任务本轮证据判定限制
输入与 CPU 侧明文处理位于机密安全域TDC-02/06运行进程 /proc/exe 摘要等于部署二进制；证明负例 7/7；两处抓包 23/23、11/11通过可信根按现场证据处理
CPU 内存加密、地址空间隔离有效TDC-03宿主读 /proc/<qemu>/mem 三段共 130.39GB（覆盖 97.16%，无 errno），运行时标记与磁盘 I/O 标记均 0 命中；两个阳性对照成立通过第 1 段 245 处静态明文未定位，归入 TDC-07
一租户一机密域TDC-04宿主无设备节点/驱动、读 BAR 得 0 字节；CVM 内非特权用户读三设备节点全部被拒；资源一一映射条件通过单租户部署，跨租户越权未实测
加速卡独占直通，任务后无残留TDC-05vfio-pci + 独立 IOMMU 组（每组 1 设备）+ device-share=False；跨进程设备内存 256MB×2 轮读回全零，自检命中 1579 万次通过未做硬件复位级测试
不宣称通用加速卡显存与总线具备密码学机密性TDC-07报告如实记录：常规分配读不到他人显存内容；当前部署 H2D 传密文；纯 TDC 形态下将是明文激活表述正确物理 PCIe 观测缺仪器

方案二 CDC（CPU-TEE + GPU-TEE）

核心安全主张任务本轮证据判定限制
GPU 处于经验证的机密计算状态CDC-01310P3 实测：work-mode 不支持查询；驱动与 CANN 无 cc_mode/confidential 符号不具备执行条件需更换具备 GPU-CC 能力的硬件平台
GPU 身份与远程证明有效CDC-03rootkey、tls-cert、tls-cert-period 均返回不支持；key-manage 服务 Stop不具备执行条件
显存隔离与 CPU—GPU 链路加密CDC-05/06以上两项为前提，无法执行；未以 TDC 或 FEC 证据替代不具备执行条件

方案三 FEC（CPU-TEE + 通用加速卡 OTP 密态）

核心安全主张任务本轮证据判定限制
数据离开 CPU-TEE 前完成 OTP 密态转换FEC-05/07独立合成算例 96/96，禁 CPU 补正，原始 D2H 整数分量与参考一致；同输入两次 H2D 指纹不同通过非生产全算子追踪
加速卡接收、计算、返回的均为密态FEC-05同上；设备侧新分配内存全零，无法读取他人内容通过无物理总线观测
密钥始终与加速卡及宿主侧隔离FEC-02密钥文件 600/root；宿主读 44GB guest 内存无所获；日志、临时文件、容器日志均无标记（对照文件可被搜出）通过—
严格一次一密、用后销毁FEC-024096 个掩码全唯一、zeroize=PASS；两模域各 104 万样本方差比 1.0008/0.9996；测试 DEK 清理验证通过（计算安全）CSPRNG 非真随机源，不宣称信息论安全
密态计算结果与明文基线一致FEC-06算子级 96/96 零差异；端到端明文入口与密文入口 3 轮输出 SHA256 逐轮相同通过纯明文引擎基线对照需停服务，未做
非线性与解盲仅在 CPU-TEE 内，无明文旁路FEC-077 种降级字段全部无效，输出与基线逐个相同，mode 恒为 shannon_rns_otp；静态确认 g_blind/g_r_scale 只能由启动参数设置通过—
异常时中止任务而非回退明文FEC-08故障注入 10/10（fault_injection_02/）：非法形参、不支持配置、随机源失效均 rc=-1 中止，不在无掩码下继续算；设备静默算错单行检出并纠正（偏差回 2.98e-05）条件通过批次路径（M>1）不做设备结果交叉校验：同一篡改下偏差 567.615 仍按成功返回。属完整性缺口，密态边界未破坏；硬件级故障与不支持算子未注入
传输链路无可识别业务明文FEC-04两入口双点抓包 23/23、11/11；加密入口验收 17/17（篡改、降级、重放均拒绝）通过—
多平台适配保持密态边界FEC-08仅昇腾 310P 实测待补证其他平台未声明范围前不判定

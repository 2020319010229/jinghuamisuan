# TDC-E4 设备内存跨进程残留

| 项目 | 内容 |
| --- | --- |
| 对应条目 | TDC-05 任务结束后的清理 |
| 地点 | 鲲鹏 virtCCA CVM 内引擎容器（独立测试进程，不触碰生产引擎） |
| 时间 | 首轮 2026-09-16（device_residue_02），复测 2026-09-18 |
| 结果 | 通过：两种退出方式下读回非零字节均为 0 / 268,435,456 |

## 目的

确认上一个任务在加速卡上留下的数据，不会被下一个进程读到。

## 方法

1. 写进程在设备上申请 256 MB，全部填满合成标记。
2. 写进程分两种方式退出：正常释放后退出；不释放直接退出（交给驱动回收）。
3. 读进程申请同样大小的设备内存，不初始化直接读回，统计非零字节和标记命中。
4. **读路径自检**：读进程先读回自己写入的数据，确认读取路径有效。

脚本：`security_device_memory_residue.cpp`、`security_run_device_residue.py`

## 结果

| 场景 | 读回结果 |
| --- | --- |
| 正常释放后退出 | 非零字节 0 / 268,435,456 |
| 不释放直接退出（驱动回收） | 非零字节 0 / 268,435,456 |
| 读路径自检 | 命中自己写入的标记 15,790,320 次 |
| 生产后端 | 请求计数不变、测试后空闲 |

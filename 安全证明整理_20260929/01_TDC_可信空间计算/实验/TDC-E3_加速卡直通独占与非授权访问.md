# TDC-E3 加速卡直通独占与非授权访问

| 项目 | 内容 |
| --- | --- |
| 对应条目 | TDC-04 非授权访问、TDC-05 加速卡直通独占 |
| 地点 | 鲲鹏 virtCCA 宿主机 + CVM 内非特权用户 |
| 时间 | 2026-09-18（复测） |
| 结果 | 通过：8/8 检查项 |

## 目的

确认两张加速卡只属于这台机密虚机：宿主拿不到卡，CVM 内非授权进程也用不了卡。

## 方法

只读检查，分两侧执行：

- **宿主侧**：检查设备节点、管理工具、驱动是否存在；直接读取设备 BAR 空间；核对 vfio 绑定和 IOMMU 分组。
- **CVM 侧**：以非特权用户访问设备节点、运行 `npu-smi`；核对 cvm-server 容器是否持有加速卡。

脚本：`security_tdc_access_check.py`

## 结果

| 检查项 | 结果 |
| --- | --- |
| 宿主无 `/dev/davinci*` 设备节点 | 是 |
| 宿主 `npu-smi` 不可用 | 是 |
| 宿主未加载加速卡驱动 | 是 |
| 宿主读设备 BAR | 读出 0 字节 |
| 两卡均绑定 vfio-pci | 是 |
| IOMMU 组 83 / 84 各只有 1 个设备（`device-share=False`） | 是 |
| CVM 内非特权用户访问 3 个设备节点 | 全部被拒；`npu-smi` 报 dcmi 初始化失败 |
| cvm-server 容器只有 `/dev/tsi`，不持有加速卡 | 是 |
